# Contributing

Bug reports and tested protocol observations are welcome.

When reporting an issue, include:

- Home Assistant version;
- integration version;
- mower model and firmware identifier;
- relevant Home Assistant log lines;
- whether the original app was connected at the same time.

Do not publish Wi-Fi passwords, PINs, private IP inventories, or packet captures
containing credentials. Test movement and blade controls only with the mower in
sight and in a safe outdoor area.
