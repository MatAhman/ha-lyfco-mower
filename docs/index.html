Lyfco E1750 Robot Mower for Home Assistant

A local Home Assistant integration for the Lyfco E1750 and potentially compatible robot lawn mowers using the EGRobot/Miotlink platform. Control stays on your local network, with no cloud account or original Android app required after Wi-Fi provisioning.

View on GitHub Installation Protocol notes

Compatibility

Tested

Lyfco E1750

  • Protocol/model identifier: M10
  • Firmware/device identifier: M10_1.5.4
  • Local TCP control on port 9600
  • Miotlink AP provisioning at 192.168.4.1

Potentially compatible

Other mowers using the EGRobot app and Miotlink platform may use a similar protocol, including models sold under:

  • Exgain
  • Lawnba
  • Ezirobot
  • Devvis

These brands have not yet been verified with this integration.

Features

Local mower control

  • Standard Home Assistant lawn_mower entity
  • Start mowing, stop/pause and return to charger
  • Manual forward, reverse, left and right control
  • Stateless cutting blade toggle button

Monitoring

  • Machine voltage and estimated battery percentage
  • Total mowing and charging time
  • Minute-resolution current charging-time sensor
  • Diagnostic alarm and transition history

Schedules & automation

  • Seven editable weekday schedules
  • Per-day edge-mowing switches
  • Mower clock synchronization including DST changes
  • Rain-sensor enable/disable control

Wi-Fi provisioning

A standalone provisioning tool can connect a factory/AP-mode mower to a 2.4 GHz Wi-Fi network. After provisioning, Home Assistant communicates directly with the mower over the LAN.

Installation

HACS custom repository

  1. Open HACS in Home Assistant.
  2. Open the menu and choose Custom repositories.
  3. Add https://github.com/MatAhman/ha-lyfco-mower as an Integration.
  4. Install Lyfco Robot Mower and restart Home Assistant.
  5. Go to Settings → Devices & services → Add integration and search for Lyfco Robot Mower.

Manual installation

Copy custom_components/lyfco_mower to your Home Assistant configuration directory so the manifest is located at:

/config/custom_components/lyfco_mower/manifest.json

Restart Home Assistant and add the integration from Settings → Devices & services.

Local-first design

The integration is designed for direct LAN communication with the mower. No vendor cloud account is required for normal operation after the mower has been provisioned onto your Wi-Fi network.

Independent project: This is an independent reverse-engineering project and is not affiliated with Lyfco, Miotlink, EGRobot or Home Assistant. Robot lawn mowers and cutting blades can cause injury; test controls outdoors and keep the physical stop control within reach.
