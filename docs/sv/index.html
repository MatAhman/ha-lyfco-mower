Lyfco E1750 robotgräsklippare i Home Assistant

En lokal Home Assistant-integration för Lyfco E1750 och potentiellt kompatibla robotgräsklippare som använder EGRobot/Miotlink-plattformen. Styrningen sker på ditt lokala nätverk och efter Wi-Fi-konfiguration behövs varken molnkonto eller originalappen för normal drift.

Kompatibilitet

Testad

Lyfco E1750

  • Protokoll-/modellidentifierare: M10
  • Firmware-/enhetsidentifierare: M10_1.5.4
  • Lokal TCP-styrning på port 9600
  • Miotlink AP-konfiguration på 192.168.4.1

Potentiellt kompatibla

Andra klippare som använder EGRobot-appen och Miotlink-plattformen kan använda ett liknande protokoll, bland annat modeller som säljs under:

  • Exgain
  • Lawnba
  • Ezirobot
  • Devvis

Dessa märken är ännu inte verifierade med integrationen.

Funktioner

Lokal styrning

  • Standardentitet av typen lawn_mower i Home Assistant
  • Starta klippning, stoppa/pausa och kör hem till laddaren
  • Manuell körning framåt, bakåt, vänster och höger
  • Knapp för att växla klippkniven

Övervakning

  • Maskinspänning och uppskattad batteriprocent
  • Total klipptid och laddtid
  • Aktuell laddtid med minutupplösning
  • Diagnostiklarm och historik över tillståndsövergångar

Schema och automation

  • Sju redigerbara veckodagsscheman
  • Kantskärningsbrytare per veckodag
  • Synkronisering av klipparens klocka inklusive sommartid
  • Styrning av klipparens regnsensor

Wi-Fi-konfiguration

Ett fristående verktyg kan ansluta en klippare i fabriks-/AP-läge till ett 2,4 GHz Wi-Fi-nät. Därefter kommunicerar Home Assistant direkt med klipparen över det lokala nätverket.

Installation

HACS som anpassat repository

  1. Öppna HACS i Home Assistant.
  2. Öppna menyn och välj Custom repositories.
  3. Lägg till https://github.com/MatAhman/ha-lyfco-mower som typen Integration.
  4. Installera Lyfco Robot Mower och starta om Home Assistant.
  5. Gå till Inställningar → Enheter och tjänster → Lägg till integration och sök efter Lyfco Robot Mower.

Manuell installation

Kopiera custom_components/lyfco_mower till Home Assistants konfigurationskatalog så att manifestet hamnar här:

/config/custom_components/lyfco_mower/manifest.json

Starta om Home Assistant och lägg sedan till integrationen från Inställningar → Enheter och tjänster.

Lokal drift utan molntjänst

Integrationen är byggd för direkt kommunikation med robotgräsklipparen på LAN. För normal drift behövs inget leverantörskonto i molnet efter att klipparen har anslutits till ditt Wi-Fi.

Oberoende projekt: Detta är ett fristående reverse-engineering-projekt och är inte anslutet till Lyfco, Miotlink, EGRobot eller Home Assistant. Robotgräsklippare och klippknivar kan orsaka personskador; prova styrningen utomhus och håll klipparens fysiska stoppknapp inom räckhåll.
